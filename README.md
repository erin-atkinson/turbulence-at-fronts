# Turbulence at fronts
Simulation setup and figure scripts for Atkinson & Grisouard, _Formation and arrest of a surface density front via strain-driven frontogenesis_, submitted to GRL.

## Simulation
LES simulations of fronts in the ocean using `Oceananigans.jl`. The aim is to be able to represent a submesoscale mixed layer with forcing via cooling and a background deformation flow.

## File setup
### src-simulation
Creation of the simulation in Oceananigans
### src-analysis
Post-processing
### src-fig
Figures

### jobs-simulation
Job submission scripts
### jobs-analysis
Job submission scripts for post-processing

### figures
Generated figures
